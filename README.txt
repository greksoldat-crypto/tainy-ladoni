ТАЙНЫ ЛАДОНИ — сайт с отправкой заявок в Telegram

Что в архиве:
- index.html — адаптивная страница сайта.
- server.js — серверный обработчик формы, отправляет заявки в Telegram.
- package.json — зависимости и команда запуска.
- .env.example — пример переменных окружения (секретного токена здесь нет).

ВАЖНО ПО БЕЗОПАСНОСТИ:
Токен бота был виден на скриншотах, поэтому отзовите его через @BotFather командой /revoke.
Создайте новый токен и НЕ отправляйте его в чат и не вставляйте в index.html.
Добавьте новый токен в переменные окружения хостинга как BOT_TOKEN.
CHAT_ID уже установлен в значение, предоставленное владельцем сайта.

Запуск локально (нужен Node.js 18+):
1. Распакуйте архив.
2. В терминале в папке проекта выполните: npm install
3. Установите переменные окружения BOT_TOKEN и CHAT_ID.
   Linux/macOS:
     export BOT_TOKEN='ВАШ_НОВЫЙ_ТОКЕН'
     export CHAT_ID='383970686'
   Windows PowerShell:
     $env:BOT_TOKEN='ВАШ_НОВЫЙ_ТОКЕН'
     $env:CHAT_ID='383970686'
4. Запустите: npm start
5. Откройте http://localhost:3000

Публикация:
Загрузите папку проекта на хостинг, поддерживающий Node.js-приложения.
В настройках хостинга задайте BOT_TOKEN и CHAT_ID как environment variables,
а команду запуска укажите npm start. Не публикуйте .env с реальным токеном.

Проверка:
Откройте сайт, заполните форму тестовыми данными и отправьте её.
Сообщение должно прийти в Telegram владельцу бота. Пользователь должен предварительно
нажать Start у своего бота. Форма не сохраняет заявки в базу данных.

Примечание: не отправляйте в форму лишние чувствительные данные.
